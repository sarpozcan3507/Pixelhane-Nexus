Gerçek zamanlı bağlantıyı kur

Supabase projenle hesap, sohbet, arkadaşlar, kulüpler ve canlı odalar etkinleşir.

1) Supabase projesi oluştur. 2) SQL dosyasını SQL Editor'da bir kez çalıştır. 3) Project URL ve publishable key değerini gir. Hizmet rolü/secret key'i asla buraya yazma.
Bağlantı ayarları bu tarayıcıya kaydedilir. Gerçek hesaplar için kendi Supabase projen gerekir.
